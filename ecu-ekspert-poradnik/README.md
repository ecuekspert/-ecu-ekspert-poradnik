# ECU EKSPERT – Poradnik elektryka samochodowego

Poradnik czujników, przebiegów, kodów błędów, ścieżek diagnostycznych i bezpieczników.

- `poradnik.html` – aktualna wersja poradnika; z tego pliku program .exe pobiera aktualizacje
- `android/` – aplikacja na Androida, budowana automatycznie
- `windows/` – pliki programu na Windows

Gotowy plik APK jest w zakładce **Releases** (po prawej stronie repozytorium).
